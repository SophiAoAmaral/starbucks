☕ Starbucks Clone

Este projeto é uma recriação da interface do site da Starbucks, desenvolvido com foco em praticar conceitos modernos de desenvolvimento front-end utilizando React e Tailwind CSS.

A proposta foi reproduzir uma experiência visual próxima da original, aplicando boas práticas de organização de código, componentização e responsividade.

---------------------------------------------------------------------------
🚀 Tecnologias utilizadas
React
Tailwind CSS
💻 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de:

Praticar a criação de interfaces modernas
Trabalhar com componentes reutilizáveis
Aplicar responsividade para diferentes dispositivos
Reforçar boas práticas no desenvolvimento front-end

A interface foi inspirada no site oficial da Starbucks, com foco em fidelidade visual e experiência do usuário.


✨ Funcionalidades
Layout moderno e responsivo
Estrutura baseada em componentes
Estilização com Tailwind CSS
Navegação simples e intuitiva entre botões e páginas


📦 Como rodar o projeto

git clone https://github.com/SophiAoAmaral/starbucks.git

cd starbucks

npm install

npm run dev
